# Every source directory: responsibility guide

[Project handoff](../../PROJECT_HANDOFF.md) · [Every source file](FILE_GUIDE.md)

This covers each directory containing source in the current delivery, including
all parent directories and deeply nested external packages. Counts exclude ignored
dependencies, local data, generated builds/caches and Git internals. A directory
name or preserved model implementation does not prove that its feature works in
our product. Full engine packages stay coherent rather than being split by extension.
Direct = source files directly inside; total = source files including descendants.
