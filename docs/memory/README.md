# VideoGen continuity archive — future ChatGPT/Codex starts here

**Updated:** 2026-11-16. The continuity archive is a permanent, version-controlled replacement for relying on a long chat window. It contains self-contained project requirements, researched sources, architecture diagrams, milestone evidence, key historical requests, next-agent instructions and an update checklist.

### Source of truth and freshness

GitHub's **live commits, PRs and CI results** override any dated snapshot in this archive. Technical claims must be labeled **VERIFIED / PENDING / BLOCKED**. Do not copy private chat details or secrets into this public repo. In particular, no user emails, tokens, personal account info, private inputs, images or model weights.

### Historical message caveat

We cannot automatically recover a complete, word-for-word export of every prior ChatGPT chat. The history document deliberately records only **available, relevant conversation facts and decisions**. If an important past promise is missing, the owner may later provide a chat export or link; add its verified content under the maintenance protocol instead of inventing it.
