Purpose: one self-contained reference of repos previously suggested in our AI image/video/audio/movie studio discussions.

IMPORTANT
- This is a historical STUDY/INTEGRATION LIST, not proof every URL currently exists or remains actively maintained.
- Verify actual upstream repository owner, latest branch/tag/commit, maintenance state, security, code LICENSE and model-weight LICENSE at implementation time.
- Public code does not mean that hosted/proprietary model weights are downloadable or free to run. API wrappers may incur fees.
- Never clone all repos into our monorepo. Build a proprietary/original product layer and integrate selected components as versioned dependencies/services.
- FreeField/OpenField variants below are DISTINCT repositories and should not be conflated.
- The original K 3.1 Pro name was ambiguous (Kling vs Kimi) and is NOT an approved open video model assumption.
- No rankings, VRAM numbers, speed claims, commercial license clearance or GPU test results are guaranteed here.

ARCHITECTURE PRIORITY: ComfyUI + optional FreeField workflows -> Wan 2.2 (video) + FLUX/Qwen (images) + Kokoro/ACE-Step (audio) + FFmpeg; LightX2V is a benchmark candidate. Our own frontend, API, job queue and movie workflow are the software we build.
